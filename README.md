# Project_0
My first project 
Personal Finance Tracker

A simple Python-based Personal Finance Tracker that helps users record their income and expenses, view transaction history, and calculate their current balance.

This is my first Python portfolio project, built to strengthen my understanding of Python programming, functions, lists, dictionaries, loops, conditional statements, and user input

Features-

Add income
Add expenses
Categorize transactions
Add descriptions for transactions
View transaction history
Calculate current balance
Interactive command-line interface

Technologies Used-

Python 3
Lists
Dictionaries
Functions
Loops
Conditional Statements
User Input

How to Run
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/FinanceTracker.git
2. Open the project folder
cd FinanceTracker
3. Run the program
python main.py

How It Works-

When the program starts, you will see a menu:

===== FINANCE TRACKER =====

1. Add Income
2. Add Expense
3. Show Transactions
4. Show Balance
5. Exit
Example
Enter your choice: 1

Enter income amount: ₹10000
Enter category: Salary
Enter description: Monthly salary

Income added successfully!

Adding an expense:

Enter your choice: 2

Enter expense amount: ₹500
Enter category: Food
Enter description: Lunch

Expense added successfully!

The program then calculates:

Income  = ₹10,000
Expense = ₹500
----------------
Balance = ₹9,500
